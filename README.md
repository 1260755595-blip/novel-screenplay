# 镜界 · 小说漫剧工作台

将小说一键拆解为分镜剧本，再由 AI 生成漫剧脚本的创意工作台。

- 项目管理：创建、编辑、删除小说项目
- 智能拆解：基于规则包自动拆解为分镜大纲
- 脚本生成：对接 DeepSeek API 生成漫剧脚本
- 规则包管理：可自定义拆解与生成规则
- 系统设置：API Key、生成参数配置

> 首次使用请先登录，然后在「系统设置」中填入 DeepSeek API Key 以启用 AI 生成。未配置时使用 Mock 模式。
