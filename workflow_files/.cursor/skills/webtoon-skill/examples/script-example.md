第1集——第1章

1-1
地点：天魔教院落，外，日
人物：叶不凡，楚紫雪
▲叶不凡被惯性甩飞，后背重重砸进枯黄的柴草堆。他满头白发混着草屑，一只手死死捂着老腰，嘴唇因剧痛而高频率抽搐，惊恐地仰视前方。
【字幕：叶不凡：百岁老登，下品阳灵根】
▲楚紫雪一袭紫色罗裙，裙摆随风扫过地面。她足尖轻点，落地无声，修长白皙的双腿在开叉的裙摆间完全显露。她嘴角挂着一抹残忍的弧度，俯视叶不凡的眼神像是在看一件廉价的货物。
【字幕：楚紫雪：天魔教魔女】
叶不凡（哭丧着脸，眼角挤出几滴泪水，哀求）：姑娘，我这都一百一十五岁了，已经入土半截，实在无力行房事，求你饶了老头子吧！
▲楚紫雪伸出涂抹着丹红蔻丹的纤长手指，猛地发力勾起叶不凡的下巴。她那张绝美的脸凑到叶不凡鼻尖，眼中邪气凛然。
楚紫雪：百年童子身，还是极罕见的阳灵根，虽然皮肉老了点，但里面能用就行。
▲楚紫雪抬手一甩，一本封皮泛着暗红色冷光、书页边缘甚至在滴落粘稠液体的秘籍《血灵功》精准撞击在叶不凡枯瘦的胸口。
楚紫雪：给你一个月时间修炼这本魔功。一个月后，配合我突破金丹。
叶不凡（双眼瞪圆，双手颤抖着抠开秘籍，倒吸冷气）：血灵功？这上面写着……修炼一次就得减寿一年，这练完我也该吃席了！
▲楚紫雪猛然侧身，右手指向远处。那里黑雾翻涌，数以万计的毒蛇在坑洞中缠绕、摩擦，发出刺耳的嘶鸣声。
楚紫雪（声音骤冷）：要么练，要么现在就去万蛇窟喂蛇，你选一个？
▲叶不凡浑身肌肉僵硬，他像受惊的鹌鹑一样缩起脖子，两只枯手死死抱紧血红秘籍。
楚紫雪（脚下一踏，身形化作一道紫烟凭空消失）：一个月后我来检查成果，别让我失望，老登。

1-2
地点：破败厢房，内，日
人物：叶不凡
▲叶不凡瘫坐在摇摇欲坠的木床榻上，他低头盯着手中的秘籍，苍老的脸上肌肉紧绷，写满了自嘲。
叶不凡（悲愤自嘲）：苟了一百年，临了临了，还要被这魔女榨干，老天爷你玩我呢！
▲虚空中毫无征兆地撕开一道金色裂缝，耀眼的金光呈波纹状向四周炸裂，巨大的半透明面板横在半空，机械的系统音在脑中炸响。
系统音：叮！检测到副作用极强的魔功，负面逆转系统激活！
▲叶不凡一个激灵从床上弹起，他由于动作过大撞歪了木床，木头发出刺耳的摩擦声。他屏住呼吸，死死锁死光幕上的文字。
叶不凡（激动得声音走调）：逆转？只要是负面效果，都能转正？
▲金色面板上，血红的警告文字自动消散，重组为翠绿色的楷书：【血灵功：修炼一个周天减寿十天，一个月后根基残废。逆转后：修炼一个周天增寿十天，一个月后修为暴涨，根基稳固！】
叶不凡（老泪纵横，仰头爆发狂笑，手掌猛击膝盖）：增寿？根基稳固？哈哈哈，老天爷，这泼天的富贵终于是轮到我了！
▲叶不凡盘膝坐定，双手迅速结印。随着他运转功法，体表涌现出一层浓郁的绿光。他头顶的白发根部竟然生出肉眼可见的乌青。
叶不凡（眼神中杀气一闪而过）：好你个楚紫雪，想拿我当炉鼎？等一个月后，谁当谁的炉鼎，还说不定呢！
▲叶不凡猛然睁眼，瞳孔中金芒直刺前方。他攥紧拳头，枯木般的皮肤下肌肉轮廓清晰隆起。
叶不凡：到那时，老夫定要让你知道，什么叫老当益壮！
