**【格式说明】**

**集标题**：第N集——第N章（不使用 Markdown # 标题）

**场景头**：地点：XX，内/外，日/夜（顺序固定：地点 → 内外 → 时间）

**台词格式**：角色名（可选表演指示）：台词内容
- 台词整体不加引号包裹
- 台词内需强调的特殊物品/名称，可正常使用引号或书名号（如「血灵功」、《血灵功》）
- 同一角色、中间无▲动作打断的连续台词，写在同一行
- 中间插入▲动作/画面后，该角色再次开口，另起一行（视为有停顿的空档，非并行台词）
- 单句台词建议 ≤50 字；超过 100 字时再拆分为多行

**【视觉描述符号】**
- **▲** 标注动作/画面变化
- **【字幕】** 标注角色身份/标签（首次出场）
- **【特效】** 标注特效
- **【音效】** 标注音效
- **系统音：** 系统/面板提示音（或【系统面板】展示数值文字）
- **角色名os：** 内心独白
- **【卡黑】** 悬念结尾（每集必须）

[注：每集500-800字，1-3个场景，结尾必须【卡黑】。场景之间不使用 --- 分隔线，直接以 N-1、N-2 编号衔接]
