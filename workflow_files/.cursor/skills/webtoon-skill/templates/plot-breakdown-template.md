## 使用说明

1. **拆解时**：每拆解6章，追加一个新批次到"剧情列表"
2. **分集时**：拆解时就直接标注"第X集"
3. **搁置机制**：批次末尾剩余不足构成完整弧线的剧情点 → 标记为"搁置"写入"搁置剧情点" → 下一批次优先读取搁置点，与新剧情点合并分集 → 合并后状态从"搁置"改为具体集数+"未用"
4. **状态管理**：
   - 拆解后默认：状态：未用
   - 创作剧本后：状态：未用 → 状态：已用
   - 批次末尾不足以成集：状态：搁置（存入搁置区）
5. **剧情编号**：连续编号，从【剧情1】开始
